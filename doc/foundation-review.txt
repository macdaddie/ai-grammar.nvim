1. INTRODUCTION                          *foundation-review-introduction*

Foundation Review checks prose with a configured local Ollama model and
places source-verified findings in the quickfix list.

Supported filetypes are `text`, `markdown` and `asciidoc`.

=============================================================================
2. SETUP                                        *foundation-review-setup*

>lua
  require("foundation-review").setup({
    ollama = {
      url = "http://127.0.0.1:11434",
      model = "gemma4:12b-it-qat",
    },
  })
<

=============================================================================
3. COMMANDS                                  *foundation-review-commands*

                                                *:FoundationReview*
:FoundationReview
        Review the current buffer and replace the Foundation Review quickfix
        list when the review completes.

                                          *:FoundationReviewCancel*
:FoundationReviewCancel
        Cancel the active review for the current buffer.

                                           *:FoundationReviewHealth*
:FoundationReviewHealth
        Check whether Ollama and the configured model are available.

                                            *:FoundationReviewApply*
:FoundationReviewApply
        Apply the correction at the current quickfix entry after verifying
        that its source text has not changed. A successful correction is
        removed from quickfix and the next outstanding entry is selected.

                                         *:FoundationReviewApplyAll*
:FoundationReviewApplyAll
        Apply all remaining corrections from the latest review. The command
        aborts before editing if any range is stale or overlaps another
        correction. A successful bulk application is one undo step and
        clears the applied entries from quickfix. Failed corrections remain.

        Undo does not restore removed quickfix entries. Run
        :FoundationReview again to create a new review.
