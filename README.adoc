
= Foundation Review for Neovim

Foundation Review is a Neovim plugin for on-demand British
English proofreading with a local Ollama model.

It reviews prose without sending document contents to a cloud
service and publishes verified findings to Neovim's quickfix
list.

== Status

The plugin is under active development.

The current implementation supports plain text, Markdown and
AsciiDoc buffers. Typst and RTF require dedicated parsers and
are not yet supported.

The complete Neovim-to-Ollama-to-quickfix path has been
verified with the default model. The automated headless suite
also verifies loading, configuration, source mapping, markup
masking, validation, cancellation, stale-result handling,
partial failure, hard-limit reporting and correction
application.

== Checks

* Spelling.
* Grammar.
* Punctuation.

Other editorial categories and sentence rewriting are
deliberately outside scope.

== Requirements

* Neovim 0.12 or later.
* A local Ollama service.
* An installed model that supports structured output.
* `curl` available in `PATH`.

The provisional default model is `gemma4:12b-it-qat`.
The plugin never downloads models.

== Installation

=== vim.pack

[source,lua]
----
vim.pack.add({
  "https://github.com/macdaddie/foundation-review.nvim",
})

require("foundation-review").setup()
----

=== lazy.nvim and LazyVim

[source,lua]
----
{
  "macdaddie/foundation-review.nvim",
  opts = {},
}
----

=== Native packages

[source,bash]
----
git clone https://github.com/macdaddie/foundation-review.nvim \
  ~/.local/share/nvim/site/pack/vendor/start/foundation-review.nvim
----

Then configure the plugin in `init.lua`:

[source,lua]
----
require("foundation-review").setup()
----

== Configuration

[source,lua]
----
require("foundation-review").setup({
  language = "en-GB",
  ollama = {
    url = "http://127.0.0.1:11434",
    model = "gemma4:12b-it-qat",
    timeout_ms = 120000,
  },
  filetypes = {
    asciidoc = true,
    markdown = true,
    text = true,
  },
  review = {
    chunk_size = 2500,
    hard_limit = 12000,
  },
  quickfix = {
    auto_open = true,
  },
  keymaps = {
    review = "<leader>ar",
    apply = "<leader>aa",
    apply_all = "<leader>aA",
  },
})
----

== Commands

`FoundationReview`::
Review the current buffer.

`FoundationReviewCancel`::
Cancel the active review for the current buffer.

`FoundationReviewHealth`::
Check whether the configured Ollama model is available.

`FoundationReviewApply`::
Apply the correction at the current quickfix entry.

`FoundationReviewApplyAll`::
Apply all remaining corrections from the latest review.

== Review and Apply Corrections

. Open a supported `text`, `markdown` or `asciidoc` buffer.
. Run `:FoundationReview` or press `<leader>ar`.
. Wait for the review to populate the quickfix list.
. Navigate findings with `:cnext`, `:cprevious` or the
  quickfix window.
. Apply the current quickfix correction with
  `:FoundationReviewApply` or `<leader>aa`.
. Alternatively, apply every remaining correction from that
  review with `:FoundationReviewApplyAll` or `<leader>aA`.

The current correction is the entry selected in the
Foundation Review quickfix list.
The apply command can be invoked from either the quickfix
window or the reviewed buffer.

The latest review replaces the previous Foundation Review
results for that buffer.
Starting another review therefore replaces the corrections
available for application.

Review never changes the buffer by itself.
Corrections are applied only after one of the explicit
application commands.

Individual application verifies that the source still
matches the reviewed text.
Bulk application preflights every correction, rejects stale
or overlapping ranges, and applies all corrections as one
undoable change.

After an individual correction succeeds, its quickfix entry
is removed and the next outstanding recommendation becomes
current.
After bulk application succeeds, all applied entries are
removed and the quickfix list is empty.
Failed or stale corrections remain in the list.

If text covered by a recommendation has changed since the
review, that recommendation is not applied.
If any bulk correction is stale or overlaps another
correction, the entire bulk operation is cancelled without
changing the buffer.

After bulk application, one `u` restores the buffer to its
state before the fixes were applied.
Individually applied corrections use Neovim's normal undo
history.
Undo does not restore removed quickfix entries; run
`:FoundationReview` again to produce a new review.

Quickfix entries contain source-verified start and end byte
positions. All corrections use warning severity.

If one chunk fails, findings from successful chunks remain
available and the quickfix context marks the review incomplete.

For command-oriented help inside Neovim, run:

[source,vim]
----
:help foundation-review
----

The help source is also available at
link:doc/foundation-review.txt[`doc/foundation-review.txt`].

== Development

Run the headless Neovim test suite from the repository root:

[source,bash]
----
nvim --headless -u tests/minimal_init.lua -i NONE -l tests/run.lua
----

Validate the architecture documents with:

[source,bash]
----
for file in docs/arch/*.adoc; do
  asciidoctor -o /dev/null "$file"
done
----

The language-quality benchmark remains deliberately deferred
until release hardening is complete.

== Privacy

Reviewed buffer contents are sent only to the configured Ollama
endpoint. The default endpoint is local loopback. No cloud
fallback is implemented.
