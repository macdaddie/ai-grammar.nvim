
= Foundation Review: Implementation TODO

== Current State

* Project name: `foundation-review.nvim`.
* Public GitHub repository: `macdaddie/foundation-review.nvim`.
* Public API and commands load in a clean Neovim session.
* Plain text, Markdown and AsciiDoc adapters are implemented.
* Reviews use asynchronous local Ollama requests.
* Validated findings are published to quickfix.
* Headless integration tests cover the critical workflow.
* A real Ollama review produces source-precise quickfix entries.

== Completed

* ADR-026 expands the response contract to seven categories.
* Exact and whitespace-collapsed quotation matching.
* Ambiguous quotation rejection.
* Length-preserving markup masking and source-byte maps.
* UTF-8-safe line-local quickfix byte columns.
* Packaged JSON Schema with deterministic Ollama options.
* Sequential chunk scheduling and partial-failure handling.
* Cancellation and stale-buffer protection.
* `vim.pack`, lazy.nvim and native-package documentation.
* Headless Neovim test workflow.
* MIT Licence and renamed public GitHub repository.
* README, Vim help and architecture documentation updated for
  the runnable implementation.

== Deferred Format Support

=== Typst

Implement a dedicated parser or Tree-sitter-aware adapter before
enabling Typst. Regular-expression masking alone is insufficient.

=== RTF

RTF requires a parser that can produce reviewable text and a
reversible source-byte map. Raw RTF shall not be sent to the model.

== Final Phase: Language Benchmark

The benchmark begins only after the plugin passes its automated and
real-Ollama integration tests.

The corpus shall cover all seven categories, British English,
protected markup, repeated quotations and clean prose.

Measure precision, recall, false-positive rate, correction accuracy,
rewrite quality, consistency accuracy and exact-source accuracy.
